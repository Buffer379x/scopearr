# Scopearr 2.0.0

Scopearr 2.0.0 redesigns the whole interface and keeps every 1.7.0 workflow. Filters, presets, columns, selection actions, tools, settings and dialogs work as before; they now sit in one consistent frame with shareable addresses, a filter drawer and mobile layouts made for phones. The database schema stays at version 18, so you can go back to 1.7.0 at any time.

## Highlights

- A new frame: a sidebar with the groups Library, Tools and System (with Settings), an accent band with the page title, and a tab bar on phones.
- Every page, filter and settings area has its own address, so links, reloads and the browser's Back and Forward work.
- Quick search (⌘K or Ctrl+K) finds pages, movies and TV series.
- The libraries' filters open in a drawer and apply with **Apply**, which shows how many files match while you choose.
- Audio track combinations: find files where one track is, for example, German **and** DTS-HD MA.
- TV series collapse to a summary row, and a collapsed series view pages by series.
- Compact cards for the libraries on phones.

## The new interface

**Frame and navigation.** The sidebar is expanded from 1600 px wide and a narrow rail with flyouts below that; on phones it becomes a drawer behind **More**. The topbar holds the breadcrumbs, the demo notice, quick search, a bell with the tools' open jobs, the sync display with **Sync now** per service, the theme button and sign-out. On phones the theme button stays in the topbar. Every entry is a real link, so Ctrl/Cmd-click opens a new tab.

**Dashboard.** Key figures link into the libraries: TV series opens the collapsed series view, Episodes the expanded one. A row shows incomplete metadata, media server matching and the storage ring, then one bar per value in each distribution; each value opens the filtered library.

**Movies and TV series.**

- The results card holds the search, the preset choice with **Save preset** and **Delete preset** beside it, and the **Filters** button.
- Active filters show as removable chips beside the page tools: mark for muxing, set tags, columns and CSV export.
- The **Columns** menu shows or hides columns with checkboxes and links to their order under Settings → Display. It replaces the temporary "All columns" view.
- The Audio tracks column shows each track as a chip with language, codec and channels; a chip's menu filters by its values or by its track.
- TV series collapse and expand from the arrow in the Info column. A page-tool button collapses or expands all of them. The collapsed view pages by series and loads only the series summaries; a series' episodes load when you open it.
- On phones each file is a compact card with title and year, one line of tags and a ⋮ menu; a sort menu replaces the column heads.

**Tools.** Muxing, Disk placement and Files & permissions share the same layout: the header actions on the band, key figures that filter by status, a card with search, presets and a Filters drawer, and the table. Row buttons and columns keep their places while jobs run. Disk placement shows each disk as a card, with arrow buttons when the row is cut off. The tool drawers' groups open to checkboxes with their counts.

**Settings.** Each area has its title and **Save settings** on the band. A floating **Save settings** button appears on long pages.

- Services shows a card per service with its status first.
- Display is split into General, Lists & columns and Colors, with the 18 palettes beside a preview. Mode and accent band now apply on **Save settings**, like the palette; the topbar button still switches the theme at once.
- Widgets, Custom tags, Tag rules and System (Info and Log) follow the same layout. The log has a Filters drawer too.

**Dialogs and notifications.**

- Dialogs are centered, open at the top of their space and grow only downward. On phones (below 740 px) they fill the screen.
- Focus stays inside a dialog, Escape closes it, and focus returns to the button that opened it.
- File & metadata renames in its head and pages through the filtered list with ↑/↓. The open file is part of the address.
- Notifications sit at the bottom right (on phones above the tab bar). Notifications with a link (Open Muxing, Show in log) stay for 8 s, as errors do.

**Sign-in and setup** use the new design, with a show-password toggle. The app icon is redrawn.

## New features

- **Audio track combination filter** (`track` with `trackOp` in the files API) for the file list, CSV export, custom-tag selection and presets. It uses measured tracks from MediaInfo or Emby/Jellyfin.
- **SDR** is derived from explicit MediaInfo and media-server measurements. New default tag rules cover **HDR SDR** and **channels 1.0 and 6.1**. With HDR or channel tag sync on, Radarr and Sonarr receive these tags, and titles tagged SDR lose `hdr-unknown`.
- **German dubbed tracks:** three new default tag rules read `DTSD` as DTS and `AC3D` as AC-3, both German.
- Existing installations receive each new default rule once; an equivalent rule of your own, or a default you deleted, is respected.
- **Settings → Display → Lists & columns:** "Show the filename below the title" and "Show audio tracks stacked", each set per list. **Row density** (Comfortable or Compact) is under General.
- **Open Muxing** link in the notification after marking files for muxing.
- Files API additions, all optional: `limit` (1 to 1000) for one request's page size, `distinct=series` for quick search, and `pageBy=series` with `summary` and `expand` for the collapsed series view.

## Fixes

- **Sonarr webhooks** no longer fail with "Service returned HTTP 500" when the webhook names an episode file Sonarr no longer has (after an upgrade or rename). Scopearr reloads that series' files instead.
- **Disk placement:** **Select** in the scan report keeps the selection it makes when it filters the list to that target. Choosing the same target again no longer clears it.
- File details name audio languages in the interface language, and the sign-in footer keeps the space after the version.
- An unknown theme, widget, column or Info action saved by a newer version no longer stops the start. Scopearr uses the default and logs a warning.
- Tag rules with the same priority now list by name in natural order (6.1 before 7.1); their run order is unchanged.
- **Faster full syncs:** a full sync builds the audio track index once at the end instead of per file. The first fill of 80,000 episodes is about a third faster.

## Upgrading

Update the container as usual and **reload open tabs once**; an older open tab reloads at most once if it meets an outdated chunk. The first start makes one backup and adds the new default rules. It also refreshes saved details from the database without reading media files, so existing MediaInfo results gain SDR; media-server values follow the next sync.

The Unraid template icon URL now uses `?v=2.0.0`. Existing containers keep their stored icon URL; see [Unraid installation](https://github.com/Buffer379x/scopearr/blob/main/docs/UNRAID.md).

## Going back to 1.7.0

Set the image to `ghcr.io/buffer379x/scopearr:1.7.0` on the same `/data`. The schema is unchanged and 2.0.0 adds no server settings. 1.7.0 ignores the following:

- Browser-only preferences: `scopearr-sidebar`, `scopearr-sidebar-groups`, `scopearr-band`, `scopearr-density`, `scopearr-tracks-stacked:radarr` / `:sonarr` and `scopearr-title-filename:radarr` / `:sonarr`. The collapsed or expanded series state is never stored.
- The `track` filter in saved presets. Such a preset shows more matches, without an error. 1.7.0 also ignores the track filter when it checks presets for duplicates.
- The new API parameters.

The new default rules remain as saved rules. If 1.7.0 rewrites files in between, SDR derived from MediaInfo returns after you come back to 2.0.0, with the next sync, MediaInfo read or rule change. The one-time refresh does not run again.
