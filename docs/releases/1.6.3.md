# Scopearr 1.6.3

Scopearr checks media folders without creating cache entries and makes tool filters, exports and dialogs more consistent.

- **Checks leave media folders untouched.** Marking files for muxing, checking jobs, previewing renames and checking path mappings use directory metadata and effective access permissions. Marking checks the physical source directory while identification retains the user-share path. Only actual write operations create media entries; the configured mux working directory retains its explicit write test.
- **Download terminal scripts in one place.** Terminal commands contains the download for all matches in the current filter, even without a selection. Selected commands retain full Copy and Download actions and the existing long-script preview.
- **Export the current result.** CSV is a Download icon in the filter footer after Reset and the scan report, before Help. Disk placement now applies the list's filters and sort to its CSV; empty results expose a disabled link.
- **Use compact tool filters.** Disk placement and Files & permissions show responsive groups separated by lines, with counts directly beside labels and multiple checklist columns on larger screens.
- **Switch tabs without jumping.** File details, MediaInfo and disk details share tab spacing. Tabbed dialogs stay at the top and retain their largest height until closed. Disk details names its file-by-disk section explicitly.
- **Find Info consistently.** Disk placement, Files & permissions and Muxing have a visible, unsortable Info heading and matching display-settings labels.
- **Reach Scan on laptops.** Scan dialogs use two columns above 900 px and a visible footer; long options scroll above the action buttons. Custom permission fields and focused owner inputs remain usable on narrow screens.

Existing empty cache folders are not removed automatically. Inspect them and use **Disk placement → Empty copies** to clean up empty copies that earlier checks may have created.

Interface additions are translated into English, German, Spanish and Italian. No database or settings migration is required. Rollback to 1.6.2 is supported with the complete Appdata directory and its matching `secret.key`.
