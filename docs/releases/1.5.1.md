# Scopearr 1.5.1

Metadata warnings now distinguish measured disagreements from less reliable Radarr/Sonarr information. System cards have equal height, password changes open in a dialog, and the log shows 25 entries per page.

- **Warnings compare filename and media server.** An Arr-only difference never creates a metadata warning, including when no media server is configured or the file has no match. A filename and measured stream that both report 1080i no longer warn because Radarr says 1080p. The differing Arr value remains visible as muted information with an explanation in file details. Genuine filename/media-server differences, such as x265 versus measured h264, retain the list warning, yellow detail row, disagreement filter and export flag. Recognition-rule conflicts and disagreements between providers remain separate findings.
- **Measured fallback before Arr.** If the filename omits resolution, codec, bit depth or channels, Scopearr now uses measured media-server metadata before Radarr/Sonarr. Known filename values remain visible, with a warning when they disagree with measurement. Source and processing keep their existing filename/Arr precedence. Audio comparison rules, combined-language handling, additive HDR and the compatible source Category hint remain available.
- **Existing caches update once.** On the first start after upgrading, a populated cache is backed up and its derived metadata is refreshed locally, without a new library sync. All pending 1.5.0/1.5.1 refresh markers share one transaction and backup, including direct upgrades from 1.4.6. Failures roll back completely, leave pending markers for a retry and do not prevent startup. Active tag-sync instances reconcile changed displayed values through the existing removal-approval safeguards.
- **Consistent System overview.** Version, Back up cache and Change password have equal height within each grid row. Change password opens the standard dialog, focuses the current-password field and clears fields on Escape, Cancel or Close. Native validation, Enter submission and sign-out behavior remain independent of settings changes.
- **25 log entries per page.** Pagination and newest-page auto-reload use 25 rows. The server's default limit remains 100 for API compatibility, and export still includes the complete filtered log.

## Compatibility and update

There are **no new database columns, schema version or saved recognition-rule fields**. The optional `apiDiffers` property exists only in cached evidence JSON and is ignored by 1.5.0. Rollback to **1.5.0 is unrestricted**: the lower disagreement count remains until that version next reprocesses metadata, when its previous interpretation can return.

Without a media-server measurement there are now no metadata-disagreement warnings. Existing presets and widgets using **Metadata disagreement** can therefore match fewer files. When a filename omits a measured trait, its displayed value and corresponding managed tags can change to the media-server value. Saved presets and rules are preserved.

Keep the supported **512 MiB memory limit without additional swap** and retain the local Appdata key with a complete backup.
