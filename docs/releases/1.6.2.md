# Scopearr 1.6.2

Scopearr separates scan options from result filters and makes manual file-check findings useful in bulk.

- **Start scans in dedicated dialogs.** Files & permissions groups Services, Checks, Target owner, Target permissions and Fixing. Disk placement groups Services, TV series and Target disks/reserve. Result panels now contain only search, presets, Shares, Kind and Status. Scan errors stay in the dialog, and active jobs prevent starting a new scan while still allowing inspection of its options.
- **Keep file-check preferences in settings.** The Unraid Files & permissions card combines default owner fields with allowed/ignored-name management and counts. Applying name edits changes the settings draft; Save settings persists them for the next scan. Verify copies with checksums moves to the Paths card and retains the existing saved preference independently of scans.
- **Export commands for manual findings.** Select Manual and Failed findings for Terminal commands; Fix selected counts only automatically fixable entries. Terminal script for all matches covers the complete current filtered open result, up to 50,000 findings. Commands group at most 100 individually quoted paths per command/value. Owner and permission changes remain distinct, explicit deletions win on the same path, and other/special or untracked-media findings add review comments. Scripts over 500 lines show a 50-line preview while retaining complete Copy and Download actions. Scopearr never executes the generated commands.
- **Know when reports were created.** Both reports start with a local scan-completion timestamp and duration. They retain the last completed report while a new scan runs and explain that state.
- **Read MediaInfo from the action row.** Read with MediaInfo / Read again follows the mux controls and is available from Overview. Successful reads switch to MediaInfo → Result; failed reads retain the current tab. Read date/version sits beside the inner section tabs and below them on phones.
- **Use one file-details icon.** Movies and episodes use Film consistently in their lists, display settings and filename field.

All interface additions are translated into English, German, Spanish and Italian. No database tables or schema version change. Existing file-check settings and the persisted Unraid checksum value are retained; rollback to 1.6.1 is supported without restoring a database backup. Keep the complete Appdata directory and matching `secret.key`.
