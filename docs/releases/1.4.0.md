# Scopearr 1.4.0

This release focuses on a consistent interface and easier everyday use throughout Scopearr, including every settings area.

- One shared style guide now governs typography, spacing, colors, icons, controls, checkboxes, surfaces and dialogs. Area stylesheets replace the accumulated override files.
- Disk placement, Files & permissions and Muxing keep their column widths and row heights when entries are removed. Long titles use two lines, paths remain available in details, and phones retain all actions through the details dialog.
- Tools badges count open jobs only. Successful/cancelled mux jobs and unstarted scan findings no longer inflate the badge. Page summaries, filtered counts and pagination explain what they count.
- Shared wording, plural forms in all four languages, adaptive file-size units, readable percentages, setup notices and consistent detail lists make the interface clearer.
- Manual scans show which Arr root folders are covered. Missing mappings have verified one-click suggestions; additional roots such as documentaries work with the same path mappings. Disk placement offers a detected Share filter when multiple shares are present. Applying a mapping highlights Scan; scans remain manual.
- Sign-in sessions slide over seven days of use, with an absolute limit of 30 days. Temporary session-check failures preserve the current view. After a real expiry, signing in restores the last library, instance, page or tool in the same browser tab.
- Preact 10.29.6, Lucide 1.53.0 and the approved GitHub Actions updates are included. Builds use Node 24.22.1 LTS. Node 26 remains deferred until its LTS start; TypeScript remains 5.9.3.

## Compatibility and rollback

The only database change is an idempotent additive `sessions.created` column. Existing sessions remain valid. Rolling back to 1.3.3 is supported; the older version ignores the extra column and resumes its previous session behavior. The container memory budget remains 512 MB. Scan, move, mux and file-fix processing remain available with their existing safeguards.

See the [interface style guide](https://github.com/Buffer379x/scopearr/blob/v1.4.0/docs/STYLEGUIDE.md), [Unraid guide](https://github.com/Buffer379x/scopearr/blob/v1.4.0/docs/UNRAID.md), and [validation report](https://github.com/Buffer379x/scopearr/blob/v1.4.0/docs/VALIDATION-1.4.0.md).
