# Scopearr 1.3.1

The main menu now has subpages. **Movies** and **TV series** open a menu with each enabled Radarr or Sonarr service by its own name; with several services, **All movies** and **All TV series** show every instance. Choosing a service filters the list, and the filter remains visible as a removable chip. **Tools** groups **Muxing**, **Disk placement** and the new **Files & permissions** page. Menus open on click or tap and support Escape and the arrow keys.

**Files & permissions** scans Radarr movie and Sonarr series folders on demand and reads metadata only; files are never opened. It reports wrong permissions and foreign owners for files and folders, hidden files, system junk such as `.DS_Store`, `Thumbs.db` or `@eaDir`, companion files (subtitles, `.nfo`, artwork, `.bif`, trickplay folders) that match no video in their folder, videos Radarr/Sonarr does not manage, other files and empty folders. Extras folders and suffixes, folder-wide artwork names and `.actors` are never reported; the allowed and ignored name lists are editable. It needs the same prerequisites as renaming: the MKVToolNix service with path mappings.

Fix one finding, a selection or all open findings; fixes run one after another and share the file-operation lock with Muxing and Disk placement. Scopearr changes permissions of items it owns and deletes findings after a confirmation. Every fix re-reads the item and refuses to act when it changed since the scan or when Radarr/Sonarr now manages the file. **Fix all** never deletes untracked videos; select them explicitly. The container runs as UID 99 without root, so it cannot `chown`. With the Unraid service, **Take ownership** replaces a foreign-owned file by a verified copy on the same physical disk; video files are included only on request. Everything else is marked **Manual** and offers terminal commands to review and run on Unraid yourself. Scopearr never runs them.

Columns in Muxing, Disk placement and Files & permissions are sortable. Sorting changes the display only; queues keep their fixed processing order.

Disk placement: items waiting for the mover now get a target and can be started individually or by selection, but never by **Start all**; without the Unraid state mount, Scopearr asks for confirmation first. Statuses use short colored tags with the full text as tooltip. Moved rows have a green remove button. The Disks column lists disk tags with their data size; the largest share is orange and the smallest green. The target appears as a disk tag, also in the details. The scan panel shows target disks as tags with an edit dialog, the Kind and Sort dropdowns are replaced by sortable columns, the log uses the Muxing terminal icon and the row speed moved to the overall progress only.

Sizes use decimal units everywhere (1 GB = 10⁹ bytes), as in the Unraid interface. Saved size filters keep their byte values and may show slightly different numbers. The disk placement reserve keeps its number as GB (20 GiB becomes 20 GB). The MKVToolNix installation now asks for 850 MB of free Appdata space.

SQLite upgrades from **schema 17 to 18 with an automatic backup before migration**. **Rollback to 1.3.0 requires restoring that pre-migration backup**, together with the existing Appdata secret key. The container budget stays at **512 MB** (`--memory=512m`). See [files and permissions](https://github.com/Buffer379x/scopearr/blob/v1.3.1/docs/FILES.md) and [Unraid setup](https://github.com/Buffer379x/scopearr/blob/v1.3.1/docs/UNRAID.md).
