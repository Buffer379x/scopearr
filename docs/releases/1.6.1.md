# Scopearr 1.6.1

Scopearr makes metadata filters easier to understand and MediaInfo tracks easier to compare.

- **Filter by a current MediaInfo read.** The new MediaInfo read filter selects files with a saved result matching their service instance, file ID, path and size. Use is not to find files without a current result. The filter appears when MediaInfo is enabled or a saved filter is active, so presets remain removable after disabling the service. Movies and episodes share the same behavior.
- **Keep manual confirmation filters in presets.** Saving a preset now retains Manually confirmed as well as MediaInfo read. Both filters have help explaining inclusion and exclusion. Existing presets remain valid.
- **Understand custom-tag management.** Help beside Settings → Custom tags explains Manual, Scopearr rule, Shared and Radarr/Sonarr Auto-Tag assignments, linked-entry counts, display names, colors and creating tags directly while assigning them.
- **Compare MediaInfo tracks in tabs.** Result, General, Video, Audio and Subtitles are separate sections. Single tracks use an Attribute | Value table; multiple tracks appear side by side with language and default/forced hints. The attribute column stays visible while wide tables scroll. The section is remembered for the session and falls back to Result when a new read no longer contains it.
- **Give file details more room.** File & metadata grows to 1060px on desktop, with the Used evidence column kept on one line. Narrow screens retain their responsive layout; rename, companion and tag dialogs retain their existing widths.

All new help is available in English, German, Spanish and Italian. There are **no database-table or settings-structure changes**. Rollback to 1.6.0 is supported without restoring a backup; that version simply does not offer the new filter or section presentation. Keep the complete Appdata directory and matching `secret.key` when updating or rolling back.

See the [MediaInfo guide](https://github.com/Buffer379x/scopearr/blob/v1.6.1/docs/MEDIAINFO.md), [tag synchronization guide](https://github.com/Buffer379x/scopearr/blob/v1.6.1/docs/TAG-SYNC.md) and [validation report](https://github.com/Buffer379x/scopearr/blob/v1.6.1/docs/VALIDATION-1.6.1.md).
