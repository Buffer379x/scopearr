# Scopearr 1.0.3

- Align Custom tags with the Tag colors table: compact, consistently bordered color, text-color, reset and delete controls with matching spacing and alignment. Keep editable names, management labels and assignment counts.
- Remove the duplicate name preview and obsolete custom-table styling. Protected or assigned tags retain their deletion safeguards, and names and colors retain their existing save behavior.

No database migration or full library synchronization is required. Media-server integrations remain read-only; outbound Emby/Jellyfin tag synchronization is not part of this release.
