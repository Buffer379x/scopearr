# Scopearr 1.2.0

Optional MKVToolNix track editing is now available under Settings → Services. Download signed Alpine packages into Appdata, configure explicit media path mappings, and mark individual files from their details. The Muxing tab lets you remove tracks, edit language/name/default/forced flags, retain chapters and attachments, choose an MKV output filename, and start all or selected jobs through a persistent single-worker queue.

Verified output is written beside the source before replacement. Optional original deletion uses Radarr/Sonarr's recycle bin, with preserved backups when deletion fails. Completion triggers an Arr rescan, internal Scopearr delta sync and optional media-server notification. Progress, cancellation, revision checks and restart recovery protect queued work. English, German, Spanish and Italian interfaces are included.

Existing installations remain opt-in: no new media mount or download is required unless enabling track editing. Add a read-write media mount manually (for example `/media`), allow UID 99/GID 100 to write, keep media outside `/data`, and set the container memory limit to 512 MiB when using MKVToolNix. Allow at least 800 MiB free Appdata for tool updates; Alpine Stable includes more dependencies than Edge. See [the mux guide](../MUX.md) for limitations and recovery.

The database migrates from schema 15 to **16**, with an automatic backup before migration. **Rollback to 1.1.x requires restoring that backup.** Preserve `secret.key` alongside the database. The Unraid template adds an optional mount, which existing containers must adopt manually. Versioned amd64/arm64 images and the stable tag are published by the approved release workflow.
