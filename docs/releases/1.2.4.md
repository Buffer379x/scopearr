# Scopearr 1.2.4

Mux tables now fit their row count and use uppercase headers matching the library. Track-table headers follow the same style. Wider options and path-check dialogs make tracks and paths easier to read on desktop, while mobile tables retain horizontal scrolling.

The status dialog combines checks and timestamps in one consistent list. Routine progress messages no longer repeat the status tag; errors, recovery instructions and preserved-backup notices remain visible. MKVToolNix version and update values use a uniform, smaller font. Existing checkbox and text spacing is preserved.

**Delete original after success is now exclusively global**, under Settings → Services → MKVToolNix → Processing. Each job copies the current setting when it is queued, including jobs created before the setting changed. Client job updates cannot override it, and later settings changes do not alter jobs already queued or running. When deletion is off, the settings show the existing explanation of preserved backups and differently named outputs. Backup recovery and deletion controls remain available in job options.

No schema migration or new settings fields are required. Rollback to 1.2.3 is unrestricted. The supported container budget remains **512 MiB**. See the [MKVToolNix guide](../MUX.md) for setup and recovery.
