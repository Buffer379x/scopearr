# Scopearr 1.7.0

This release polishes the existing interface and reduces background work without changing workflows or the database schema.

- Stable search/filter controls, centered navigation and counters that do not move surrounding entries.
- Correct Settings highlighting and current-page accessibility; clearer state-filter operators, improved light-theme contrast and compact mobile selection actions.
- Readable translated API/network errors, with JSON errors from API endpoints.
- Compressed static assets, browser caching and ETags; language catalogs load on demand before the interface changes language.
- Indexed status totals and webhook queues, and shared polling that pauses in hidden tabs and refreshes on return.
- Mux job-list polling uses metadata checks without opening media files. Explicit checks, marking and starting retain the full read test.
- Demo libraries remain visible after saving. Unchanged initial saves do not log false changes, and failed sign-ins do not record unknown usernames.
- Removed unused code, translations and tokens and consolidated stylesheet rules. CSV formats remain unchanged.

**After updating, reload the page once.** An older open tab also reloads at most once if it encounters an outdated lazy chunk.

Container: `ghcr.io/buffer379x/scopearr:1.7.0` (also promoted to `stable` after release checks).

See the [validation report](https://github.com/Buffer379x/scopearr/blob/main/docs/VALIDATION-1.7.0.md). The host-specific Unraid sleeping-disk check still requires a real Unraid installation.
