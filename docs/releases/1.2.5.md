# Scopearr 1.2.5

Mux jobs now persist their final result independently of revision changes from concurrent writers. Locked final writes retry for up to two minutes and remain queued in memory for later retries if storage is still unavailable. A watchdog recovers stale running jobs when no worker or rescan handler owns them. Jobs interrupted after replacement require output review and a retry of the rescan.

Reidentifying changed tracks now normalizes duplicate default-track flags, matching newly created jobs.

Output verification accounts for removed longer tracks: retained track durations are used when available; otherwise a bounded 2% shortening allowance applies. Unchanged track selections retain the one-second tolerance, and output longer than the original plus one second is always rejected. Source identification allows two minutes and output checks five minutes. Verification failures retain the original before replacement and include concrete duration or track-count details in the terminal.

The timestamped, path-redacted terminal now covers verification, replacement, Arr rescan states, the queued Scopearr sync and media-server notifications through the final result. Finishing mkvmerge is labeled as an intermediate step. Waiting for Radarr/Sonarr is visible in the status and terminal footer. A five-minute rescan timeout leaves the new file in place and offers **Retry rescan**. Error messages appear directly beneath the status tag and as tooltips on attention states.

The dashboard remembers its selected library scope locally in the browser. Muxing remains visible whenever MKVToolNix is enabled, including an empty queue; its badge appears only when jobs exist. Mux tables use all columns in a fixed order, with the column switch and display setting removed. Waiting jobs use orange, distinct from yellow warnings. Media-server contributing-library and outbound-tag groups use consistent 10px vertical spacing.

The backend builds with Go 1.27.3, fixing the crypto/x509 certificate-validation advisory GO-2026-6809 detected by the release security scan.

No schema migration is required. Legacy mux-column fields remain valid for older clients, allowing unrestricted rollback to 1.2.4. The supported container budget remains **512 MiB**. See the [MKVToolNix guide](../MUX.md) for setup and troubleshooting.
