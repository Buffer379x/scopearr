# Scopearr 1.0.1

- Mark tag-color values actually supplied by Emby/Jellyfin metadata with an accessible circled-exclamation tooltip, without changing tag visibility or upstream synchronization.
- Respect the spelling of fixed recognition-rule results in tag labels, including a manually entered `VP9`. Keep normalized internal codec/filter/color keys so existing presets, comparisons and tag settings continue to work. Label selection follows enabled rule priority, with override rules taking precedence. ISO language labels remain localized.
- Place TV view and Pagination beside each other in Settings → Display, stacking them on narrow screens like the language/theme cards.
- Add an Additional settings card. Group known resolutions below 720p as **SD** in the dashboard by default. An optional, initially disabled second checkbox also applies grouping to library cells and resolution filter options; it is available only while dashboard grouping is enabled.
- Keep unknown resolution separate. Dashboard SD drilldowns, inclusion/exclusion filters, presets, bulk actions and CSV selection use the same complete SD predicate. Existing exact-resolution presets retain their original meaning. File details, CSV values and outbound tag synchronization keep the original resolution.

No full library synchronization is required for the new labels or grouping. Save appearance changes explicitly. After upgrading, dashboard SD grouping is enabled automatically; list/filter grouping stays off until selected.
