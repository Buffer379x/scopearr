# Scopearr 1.4.3

Shared Radarr/Sonarr roots now retain their origin throughout scanning, and everyday selection, help and confirmations are simpler.

- Disk placement and Files & permissions identify roots by stable instance IDs and normalized Arr paths. Shared roots work with unnamed instances and trailing or repeated slashes. The placement report shows both instance labels and **From Arr** before **Scanned**, with an explanation when items were excluded or their paths prevented scanning.
- Movies and TV series select only the visible page, including visible season context. Series/season checkboxes have partial states based on those rows. Paging, sorting, search, filters, presets and view changes clear selection. Counts remain in toolbar actions; the selection bar, global-selection endpoint and extra group counters are removed. Explicit selected-file tag writes remain supported.
- Tool activity appears as a spinner and short text beside the results count. Per-row progress and scan cancellation remain available.
- Disk placement and Files & permissions combine **Last scan** and **How scanning works** in one scrollable help popover. Muxing adds **How muxing works**. Report buttons remain on the two scanners.
- Fixed-list hints stay inline beside their names. All six settings areas share one heading; Custom tags now saves colors through **Save settings** in that heading. Tag-rule guidance moves from four permanent boxes into sectioned help beside the title.
- A single mux marking needs no confirmation. Multiple markings have one short confirmation and process the entire visible page sequentially, with button activity and one outcome toast. Existing markings are silently skipped; protected queued/running jobs and retained backups survive unmarking. Tag changes, moves, fixes and mux starts use short confirmations with a verb button. Existing file and mover safeguards remain in place.

## Compatibility and rollback

No database schema migration or dependency update is required. Rollback to 1.4.2 has no restrictions. Root provenance is internal and is not stored in media rows. Run a fresh manual scan to refresh previously saved root counters. Retain the **512 MiB memory limit without additional swap**.
