# Scopearr 1.2.3

Use one Arr → Scopearr path mapping for every Radarr and Sonarr instance. Existing per-instance mappings merge automatically in instance-ID order: duplicate roots appear once and the first target wins a conflict, with a server warning. Settings mirror the global mapping into every instance's legacy field for rollback to 1.2.2.

**Import root folders** reads enabled Arr services and adds missing roots when an existing `/media` directory can be suggested. Roots that need manual mapping remain listed. **Check paths** checks the current unsaved mapping and working-directory input, reports syntax line numbers, directory access/free space, Arr roots and cached file samples in a dialog. Individual service failures do not hide the remaining results. Root-folder configuration paths are visible only to authenticated users; sample media paths remain private.

The Muxing page now uses the library table layout with selection, options/terminal buttons, filename, size, source service, colored status, progress and actions. Configure column visibility/order under Settings → Display when MKVToolNix is enabled. Status opens a checklist; options and the path-redacted live MKVToolNix log open in dialogs. Terminal updates use bounded offset reads; logs are removed with jobs.

**Save mux options before starting.** Saving a draft, failed or cancelled job makes it **Ready**. Existing drafts remain drafts and must be saved once. Start selected/all queues only ready, failed and cancelled jobs; warnings report concrete file-check failures. Changed-source jobs must be identified again before their options can be saved. Existing replacement, backup, rescan and working-directory safeguards remain in place.

Service tabs stay in one horizontally scrollable row on desktop and mobile. MKVToolNix settings reuse the service layout with correctly sized radios, checkbox-first labels, consistent vertical spacing and compact track controls. English, German, Spanish and Italian translations are included.

No schema migration is required (schema 16). Keep the supported **512 MiB** container budget introduced in 1.2.2. See the [MKVToolNix guide](../MUX.md) for setup, statuses and recovery.
