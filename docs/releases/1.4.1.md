# Scopearr 1.4.1

This release refines the shared interface throughout Scopearr, including settings, while keeping scan, file-fix, move, mux and library workflows available.

- Dashboard distributions share their chart, list and expansion layout. Language entries align in one column, Unknown uses the same flag box, and widget rows stretch evenly.
- Every TV column is sortable. Title order groups series and seasons; other columns show a flat episode list with clear episode labels. A third click restores the default. Movie and TV sort preferences are independent, and CSV follows the same order.
- Libraries and tools share their search/preset row, filter footer and floating surfaces. Tool presets save list filters only. Tool scans and progress now sit beside their results; reports, scan information and help have distinct labels.
- Disk placement and Files & permissions offer independent Shares filters inside the expanded Libraries group. Missing mappings remain actionable above the results. Files & permissions gains a CSV export that respects filters and sorting across all pages.
- Disk tags explain source/target, size and file/folder counts through accessible tooltips. Overflow disk chips retain their details action. Detail tables, reports, rules and editors share table recipes and keyboard-accessible sorting.
- Display settings have General, Lists & columns and Colors tabs with unsaved-change indicators. Ordered lists, card actions and editor controls are consistent; Widgets, Services, System and custom-tag settings use more compact layouts. Save remains reachable while scrolling.
- A permanent stylesheet ownership guard prevents one area from silently overriding another area's base selector.

## Compatibility and rollback

There is no database schema change. Tool presets use the existing presets table; 1.4.0 ignores these tool namespaces, so rollback is unrestricted. Existing library presets and processing safeguards remain in place. Dependencies remain on the versions approved for 1.4.0. The container memory budget remains **512 MB**.
