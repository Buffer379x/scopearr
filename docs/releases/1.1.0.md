# Scopearr 1.1.0

- Add multiple named Radarr, Sonarr, Emby and Jellyfin instances. Keep the synchronization timezone visible above service tabs and add/manage connections through a dedicated dialog.
- Scope cached files, schedules, webhooks, storage, links, external tags and ownership by immutable instance identity. Preserve existing connections and credentials during migration, including legacy webhook URLs.
- Combine matching library types with an instance filter while keeping separate managed files and instance-specific season analysis, custom assignments and presets.
- Add optional, independently configured outbound tag synchronization to Emby and Jellyfin. It is disabled by default and writes to matched movies and individual TV episodes. Media-player custom-tag import is not included.
- Combine tags from all contributing Arr instances and file versions before updating one media-player item. Preserve existing tags or confirm replacement/removal through a live preview.
- Use dedicated Emby tag operations and guarded Jellyfin metadata updates with unrelated metadata preserved and write results checked. Ambiguous identities are skipped; no scan, refresh or media-file operations are requested.

See [named service instances](../SERVICES.md) for configuration and behavior. Back up Appdata, including `secret.key`, before upgrading. Required database upgrades create a consistent backup automatically. A rollback across the schema upgrade requires its matching earlier database snapshot. Unraid updates remain operator-managed.
