# Scopearr 1.2.6

File details now group the title and filename in a compact identity section below the mux actions. Audio tracks and media-server matching share one section, track titles appear inline in parentheses, and matching help opens from the question mark. Outlier and recognition-conflict sections use consistent headings, borders and spacing on desktop and mobile.

Rename movie and episode files directly from the pencil beside the filename. The original extension is preserved. Enable the MKVToolNix service and configure the media mount and path mapping first; installing mkvmerge is not required for renaming. Remove any mux job for that file before renaming. Sonarr must recognize exactly the same series and episodes in the proposed name, including multi-episode files.

A preview detects same-directory companion files such as subtitles, metadata and artwork. Choose whether to rename them too or change only the media file. Existing targets are protected, changed companion lists require another review, and a companion failure rolls back completed renames. After a successful rename, Scopearr rescans Radarr/Sonarr, queues its library update and optionally notifies connected media servers. A rescan timeout reports that the file was renamed and schedules a delayed library refresh. Other refresh failures leave the renamed file in place and request a manual synchronization.

Radarr/Sonarr automatic naming can change the filename again during future imports or upgrades. Companion files are renamed only after confirmation. Extra-file discovery after rescanning depends on the Arr configuration; verify subtitles and metadata in your own Radarr/Sonarr installation. End-to-end acceptance against a live personal Arr installation remains a manual check.

Mux terminal redaction preserves format names and source references such as `MPEG-1/2 Audio Layer II/III`, `AVC/H.264` and `src/common/memory.h`, while hiding absolute media paths. Failed MKVToolNix jobs now explain damaged-source allocation errors, disk-space errors, permissions and unreadable formats. Invalid-data warnings alone do not fail a job. Repair or replace damaged input; a newer MKVToolNix in the Current (edge) channel may handle it. Scopearr does not retry with another tool or change package channels automatically.

No schema migration is required; rollback to 1.2.5 remains unrestricted. The container budget stays at **512 MiB**. See the [MKVToolNix guide](../MUX.md) for setup, rename behavior and recovery.
