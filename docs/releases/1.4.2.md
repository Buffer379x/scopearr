# Scopearr 1.4.2

Scopearr now explains every disk-placement result, adds selection-based library actions and refines tables and settings throughout the app.

- Disk placement detects folders missing from every disk, verifies mapped root directories against the actual Unraid user shares and recognizes renamed or nested share mounts. Unsafe or ambiguous replacements are blocked. Series whose intact seasons occupy different disks appear as **Seasons spread** when scanning by season; choose series grouping to consolidate them.
- Compact **One disk** results remain searchable. An empty search offers to show hidden one-disk matches. The scan report includes per-root decisions, actual share paths and filter shortcuts; missing mappings and path warnings remain visible above results.
- Movies and TV series have a fixed selection column, page selection and **Select all matching** (up to 10,000 files). Series and season checkboxes include off-page episodes and visible season context, with partial-selection states. Paging and sorting preserve selection; filters, presets and view changes clear it.
- Mark selected files for muxing sequentially, with a 200-file limit, progress, cancellation after the active file and a result summary. Remove selected mux markings while preserving queued/running jobs and retained backups. Apply tags to explicit selections. Actions affecting multiple entries ask for confirmation, including tool starts and fixes. A configurable mux info icon opens the corresponding job.
- Tables measure translated headers, fit their standard columns at 1440 px and keep control columns free of ellipses. Progress remains a separate sortable column with a compact bar. Edit/delete actions sit at row ends; ordered-list row lines are continuous.
- Settings use consistent spacing and content-width tabs. Tag rules put search below the heading and actions at row ends; tag colors put their field below the description. **Lists & columns** is one card with Icons and four column tabs, independent dirty indicators and active-tab reset. Media servers show their last successful match date and matched-file count while reflecting source sync activity.

The unselected filtered-view tag action is replaced by Select all matching → Set tag. The bulk default-rule reset and redundant rule count are removed; the legacy reset endpoint remains available for compatibility.

## Compatibility and rollback

There is no database schema change and no dependency update. Mux icon position and visibility use optional settings metadata alongside legacy-compatible info lists. Rollback to 1.4.1 starts without a layout reset; **run a new disk-placement scan after rollback** to replace the new statuses and compact rows. Keep the **512 MiB memory limit without additional swap**.
