# Scopearr 1.5.0

Media details now handle cropped video and common speaker layouts correctly, and tool tables keep their status tags and progress aligned in every language.

- **Whole status tags and aligned progress.** Disk placement, Mux and Files & permissions measure their status column from all translated short labels. Tags no longer gain a stray ellipsis. Progress bars and idle dashes start at the same left edge; percentages use a fixed, right-aligned slot that fits 100 %. Mux uses short Review and Attention labels while retaining the full accessible description. Measurements refresh after language changes and font loading.
- **Correct cropped video tiers.** Emby and Jellyfin metadata such as 1912 × 796 now counts as 1080p, and 3832 × 1600 as 2160p. Cropped 720p, 1440p and 8K encodes retain their tiers too; missing dimensions stay unknown, interlacing and SD behavior are preserved. This removes false disagreements with filenames and Arr qualities.
- **Readable speaker layouts.** Layouts such as 5.1(side), 7.1(wide), 6.1(back) and quad display as 5.1, 7.1, 6.1 and 4.0. Unknown layouts retain their channel count without guessing an LFE channel.
- **Specific sources remain specific.** Filename sources that refine the Radarr/Sonarr category (UHD, BDRip, BRRip → BluRay; DVDRip → DVD) are no longer reported as metadata disagreements. The filename remains authoritative; the broader Arr value stays visible with a Category hint. Genuine differences such as WEB-DL versus BluRay, or WEBRip versus WEB-DL, remain warnings. Custom source values still compare strictly. There is no majority vote between services.
- **Red exclusions and a consistent System overview.** Is not and None of filter chips and selected filter buttons use the error color in light and dark themes. Version, Back up cache and Change password share one three-card overview, adapting to two plus one cards on tablets and one column on phones. Password changes retain native validation, password-manager attributes and sign-out behavior, independently of settings changes.

## Compatibility and update

On the first start after upgrading, Scopearr creates a consistent database backup for a populated cache and refreshes derived media details, **without contacting Emby, Jellyfin, Radarr or Sonarr**. Empty caches need no refresh backup. It updates only changed file records and marks active tag-sync instances for reconciliation. A failed refresh rolls back completely, records a warning and retries at the next start; the application still starts.

There are **no new database columns, schema version, recognition rule fields or dependencies**. Rollback to **1.4.6 is unrestricted**; that version can read the refreshed database and saved rules, although its next metadata reprocessing can restore the older interpretation. Keep the local Appdata key with any complete backup.

Saved filter presets are kept as written. Presets containing **6 ch** for 5.1 tracks or **720p** for cropped 1080p files may match fewer files after the correction; adjust them if needed. Keep the supported **512 MiB memory limit without additional swap**.
