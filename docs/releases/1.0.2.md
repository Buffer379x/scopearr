# Scopearr 1.0.2

- Add an SD row to resolution tag colors whenever dashboard SD grouping is enabled. Configure its background, text color and display preference with the existing controls. Disabling SD hides the color row while retaining saved overrides for reactivation.
- Count all known resolutions below 720p in that row, including media-server resolutions without a filename rule. Reuse the cached catalog aggregation without extra database scans or upstream requests. SD remains a virtual display group and cannot be deleted or synchronized as a real media tag.
- Sort all checkbox filter menus alphabetically by their visible, localized labels, including SD, custom names and recognition-rule spellings. Unknown (or no custom tags) always appears last. Canonical query values and existing presets remain unchanged.

No full library synchronization is required. Existing SD grouping preferences are retained; save appearance changes explicitly.
